# 定投助手 (DCA Tool)

> “大钱不是靠频繁折腾赚来的，而是在耐心的等待中赚来的。”\
> —— 查理·芒格 (Charlie Munger)

> “如果投资者能够保持理智，定期买入代表美国优秀商业集合的低成本指数基金，他将战胜绝大多数专业投资者。”\
> —— 沃伦·巴菲特 (Warren Buffett)

---

**定投助手**是一个为长期主义者打造的资产定投辅助与策略回测工具。

在喧嚣的金融市场中，“市场先生”每天都会敲门报出各种极端的价格——狂热时令人目眩，悲观时让人窒息。然而，投资的真谛从来不是试图预测下周的风向，而是用确定的纪律抵御人性的弱点。

本工具基于 **SPY（标普 500）**、**QQQ（纳斯达克 100）** 与 **VGT（信息技术精选）** 三只长跑标的，将**机械化的定期定额投资（DCA）**、**近月回撤金字塔加仓**与**极度恐慌逆向增投**融为一体。它不仅帮助你在日常平静时有条不紊地积累筹码，更能在市场大幅折价或歇斯底里时，温和而坚定地提醒你递出买单。

全套系统基于纯原生现代 Web 技术构建，**零第三方运行依赖**，代码与历史数据完全驻留在本地，像一柄磨砺得当的古董怀表般安静、可靠、开箱即用。

## 投资哲学与策略设计

### 1. 为什么选择这三只宽基标的？

我们不鼓励投资者将积蓄押注在个别企业的起落上。正如巴菲特所言，购买指数就是买入整个经济体最精良的那批生产力：

- **SPY (标普 500 ETF)**：全美乃至全球商业皇冠上的五百颗明珠，涵盖各行各业的领头羊，是陪伴国运复利的核心基石。\
  *关于标的选择的一点坦诚说明*：许多奉行低费率原则的朋友或许会问，日常定投中大家更偏爱先锋领航（Vanguard）费率极低的 **VOO**，为何这里选用 SPY？**原因在于历史数据的完整度**。VOO 诞生于 2010 年秋季，虽然是实操定投的上佳选择，但若仅看 2010 年以后的行情，便无从窥见 2000 年互联网泡沫破裂与 2008 年次贷海啸这两场百年罕见的大考；而 SPY 始于 1993 年初，拥有跨越 30 余年、历经多轮大牛大熊的完整历史走势。唯有接受过极端行情的淬炼，定投和加仓策略的韧性才更具说服力。
- **QQQ (纳指 100 ETF)**：聚集最具创新活力与技术护城河的先锋企业，分享科技浪潮带来的超额成长红利。
- **VGT (先锋信息技术 ETF)**：纯度更高的信息时代基础设施，代表了人类社会数字化与智能化的前进引擎。


### 2. 基石：定投纪律（DCA）

“不择时，便是最好的择时。”\
每个月在约定的日子（如发薪后的 1 日或 15 日），雷打不动地投入一笔基准金额 $N$（默认 2,000 USD）。牛市买到的份额少一点，熊市买到的份额多一点。时间会抚平波动的褶皱，将精力归还给生活。

### 3. 折价时的从容：近月回撤金字塔

当优质资产打折促销时，普通的消费者会兴奋，但许多投资者却会害怕。\
金字塔策略以**从上月对应日（月底对齐）至当日、包含当天的滚动近月窗口内的最高价**为锚点：
- 回撤不足 5% 时：维持常态，投入 $1N$；
- 回撤达到 5% 时：步入打折区，投入 $2N$；
- 回撤达到 10% 时：投入 $4N$……跌得越深，金字塔基底越厚实（最高可至 $38N$）。

它不抄绝对底部，但确保你在估值洼地买入最多的便宜筹码。

### 4. 逆向者的从容：恐慌与贪婪加投

> “在别人贪婪时恐惧，在别人恐惧时贪婪。”

华尔街常被恐慌情绪所统治。当 CNN **恐慌与贪婪指数（Fear & Greed Index）** 跌破极度恐慌阈值（默认 10）时，往往意味着流动性挤兑与绝望情绪蔓延。\
此时，策略会发出额外的逆向买入信号（默认追加 $3N$）。为了避免在震荡期反复磨损，系统设计了 **+5 分缓冲回升带**：必须等市场情绪重新达到或超过 15 分，下次下穿才会重新蓄力触发。

## 三分钟快速上手

我们崇尚简单、朴素的工具，不给你的系统增加任何负担。

### 运行环境
你只需要一台安装了 **Node.js 20 或更高版本** 的电脑。无需安装任何第三方 npm 依赖包（`package.json` 没有臃肿的依赖树，直接使用纯标准库）。

### 启动服务
1. **Windows 用户**：直接双击项目根目录下的 `start.cmd`。
2. **终端用户**：在项目目录下运行：
   ```sh
   node server.mjs
   ```
3. 在浏览器中打开：
   ```text
   http://127.0.0.1:4173
   ```

> [!TIP]
> 默认情况下，服务仅监听本地回环地址（127.0.0.1），安全私密。若想部署到家庭局域网服务器或静态发布到 GitHub Pages，请参阅[部署说明文档](docs/deployment.md)。

## 功能全景图

### 全历史画卷与双图联动
- **K 线与情绪同频共振**：上方是经**前复权（分红再投资）**处理的真实价格走势，下方是 CNN 恐慌与贪婪指数。两张图在时间轴上严丝合缝，滑动任意一处，两方皆能实时联动。
- **长周期洞察**：支持日线、周线、月线自由切换，既可细看数十个交易日的微澜，也可回望十余载跨越牛熊的壮阔浪潮。

### 严谨诚实的回测对比
许多策略展示只夸大收益，却隐藏了现金拖累的代价。本工具的**策略回测对比**板块提供两种公道的视角：
1. **各自投入模式**：各策略按各自触发的实际资金，计算期末总资产、累计盈亏与 **XIRR 年化内部收益率**。
2. **同一供资计划模式（推荐）**：假定投资者为所有策略准备了相同规模的资金池。在股票未触发加仓买入时，**闲置现金按 3% 年化复利计息**。这让你清晰看到：**在漫长的等待期里，现金并没有睡大觉，它在产生利息；而一旦机会来临，子弹便能从容打出。**

### 真金白银的资金需求推演
定投最怕的是“跌到深处却无钱可用”。\
系统提供单独的**历史资金需求分析**，按月份统计累计投入、月均开销以及历史上最为极端的“单月最高资金需求”。你能够清晰看清：如果历史上最严峻的危机重演，你的现金流备用金是否足够支撑。

### 无声陪伴的桌面小窗与触控手势
- **桌面浮窗**：在大屏幕向下浏览回测报告或资金明细时，主图会自动凝缩为右下角优雅小窗，保留标的切换与缩放联动，绝不错失大局。
- **触屏友好**：在手机与平板上支持双指缩放、平移拖动与自适应排版。

## 策略规则与计算公道

所有的智慧都建立在清晰无欺的规则之上：

| 规则维度 | 机制说明 |
| :--- | :--- |
| **定投触发日** | 每月指定 1～31 日，不存在的日期对齐当月月末。若遇周末休市则顺延至下一可用交易日；若上月定投顺延至本月，不挤占本月独立额度。 |
| **金字塔回撤基准** | 锚定从上月对应日（月底对齐）至当日、包含当天的滚动近月窗口内的最高价（High），以当日收盘价（Close）测算回撤幅度。 |
| **金字塔加仓档位** | 回撤 $< 5\%$ 投 $1N$；$\ge 5\%$ 投 $2N$；$\ge 10\%$ 投 $4N$；每加深 $5\%$ 追加 $2N$，单笔封顶 $38N$。 |
| **恐慌触发机制** | 恐慌指数日终值从不低于阈值跌破阈值（默认 10）时，触发加投 $M \times N$（默认 $3N$）。 |
| **恐慌防抖保护** | 触发后进入冷却，指数必须先达到或超过 $\text{阈值} + 5$（默认 15），方可重新具备触发资格，防止临界震荡。 |
| **回测撮合价格** | 信号于收盘确定，回测一律于**下一可用交易日开盘价（Open）**成交；不使用未来数据，杜绝偷窥效应。 |
| **除权除息口径** | 采用 Yahoo Finance Adj Close 反推的前复权序列，忠实模拟分红全额再投资的长期复利轨迹。 |

## 数据源流与理性边界

任何诚实的投资工具都必须坦承其能力的边界与数据的来处：

1. **ETF 行情**：通过接口获取 Yahoo Finance 每日数据，本地缓存于 `public/data/` 目录。
2. **情绪指数**：
   - 2021-02-01 至今：直接对接 CNN 官方日终接口；
   - 2011-01-03 至 2021-01-29：采用开源社区 [whit3rabbit/fear-greed-data](https://github.com/whit3rabbit/fear-greed-data) 整理的历史存档。
3. **数据更新机制**：本地内置独立抓取与调度器，交易日美股收盘后自动获取最新快照。详情参阅[数据更新与部署说明](docs/deployment.md)。

> [!NOTE]
> **关于 SPY 与 VOO 的数据口径**：\
> 回测数据完全采用 SPY 真实的前复权历史序列。尽管 SPY（管理费率约 0.09%）相比 VOO（约 0.03%）存在极细微的费率差异，但它提供的 30 余年完整行情，为观察极端下行周期的加仓效果提供了不可替代的实证价值。

## 工匠技艺与工程架构

本项目的代码遵循极简、克制与长青的现代前端美学：

- **零打包器负担**：浏览器端与服务端直接采用原生 ES Modules，不使用 Webpack/Vite 捆绑，代码即源码。
- **纯粹 Canvas 2D 渲染**：高性能手写 K 线图与情绪曲折图，像素对齐清晰，告别臃肿的第三方图表黑盒。
- **领域核心独立**：计算逻辑（复权、金字塔、回测、XIRR）全部封装在 `public/js/domain/` 纯函数中，Node.js 单元测试与浏览器界面共享同一套代码。

### 开发者指令

```sh
# 运行单元与逻辑测试（无需额外测试框架，使用 Node.js 原生测试器）
node --test test/*.test.mjs

# 手动抓取最新外部数据
node scripts/update-data.mjs

# 构建静态部署产物（输出到 dist/ 目录，供 GitHub Pages 静态托管）
node scripts/build-site.mjs
```
